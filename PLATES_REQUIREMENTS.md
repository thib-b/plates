# Petri Plates - Requirements and Specifications

This document outlines the requirements and specifications for each plate simulation in the project.

## Core Plates (User-Defined)

### 1. Color-Based Organisms Plate (`plates/petri.html`)
- **Behavior**: Static organisms with adjacent growth
- **Interactions**: Color-based (merge, avoid, or compete based on color similarity)
- **Rules**: 
  - If colors are close enough: merge
  - If colors are very dissimilar: compete
  - If colors are somewhat dissimilar: avoid each other
- **Visual**: Each colony starts with its own color
- **Status**: Working (user's original plate)

### 2. Slime Mold Plate (`plates/slime.html`)
- **Behavior**: Based on reference: https://openprocessing.org/@u429398/2213463#code
- **Features**: Moving particles that deposit and follow trails
- **Visual**: Particles move and create trail patterns similar to slime mold growth
- **Constraint**: Must be contained within a plate (circular boundary)
- **Status**: Working (user confirmed)

## Known Issues and Fixes Applied

### Fixed Issues:
1. **Particle Life Plate**: Plate was in top left corner instead of center
   - Fix: Corrected angle conversion in constraint code (`atan2` returns radians, `cos/sin` expect degrees with `angleMode(DEGREES)`)

2. **Chaos Game Plate**: Speed too fast
   - Fix: Reduced `pointsPerFrame` from 50 to 5, adjusted slider range

3. **L-System Plate**: Black screen due to excessive string length
   - Fix: Reduced default iterations from 10 to 6, added MAX_STRING_LENGTH guard (50000), capped slider at 8

4. **Perlin Noise Terrain Plate**: Black screen
   - Fix: Simplified terrain generation to test pattern, brightened colors, added safeguards

### Remaining Broken Plates:
1. **Fractal Garden Plate** - Black screen (TurtleGFX library may not be loading)
2. **Chromatic Reaction Plate** - Black screen (p5.palette library may not be loading)
3. **Voronoi Plate** - Not moving (static visualization only)
4. **Perlin Noise Terrain Plate** - May still have issues
5. **L-System Plate** - May still have issues

## General Requirements for All Plates

1. **Plate Boundary**: All simulations must be contained within a circular plate of radius 300px
2. **Centered**: Plate must be centered on screen
3. **Navigation**: Each plate page must have a link back to index.html
4. **Controls**: Collapsible controls panel (hidden by default)
5. **Consistency**: Similar UI/UX across all plates
6. **Responsive**: Must handle window resizing
7. **Keyboard Shortcuts**:
   - R: Restart
   - S: Save (as PNG)
   - (Others as appropriate)

## User Preferences

1. **No plate size control**: User requested removal of plate size controls
2. **Background**: Plate should have unicolor background (no inner circles)
3. **Organism behavior**: For petri/slime plates - organisms should:
   - Start in random positions
   - Grow adjacently (not move)
   - Form blooms/colonies
   - Mycelium patterns (once colonies are large enough)
   - Color interactions: merge/avoid/competition
